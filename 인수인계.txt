print-compare 인쇄 검수 도구 — 인수인계서
===========================================

1. 받는 사람이 처음 할 일
-------------------------

1) 전달받은 ZIP을 C:\ 같은 경로에 풉니다. 자동으로 C:\print-compare가 됩니다.
2) 설치.bat을 더블클릭합니다.
3) GitHub와 Codex 브라우저 로그인 창이 열리면 로그인만 승인합니다.
   Codex는 담당자 개인 ChatGPT 계정을 사용해도 됩니다.
4) 설치 결과가 모두 [완료]이면 인수인계가 끝난 것입니다.
5) 다음부터는 시작.bat만 더블클릭합니다.

설치 전에 시작.bat을 눌러도 설치 프로그램이 자동으로 먼저 열립니다.

두 명이 인수인계받으면 두 사람 모두 각자의 PC에서 위 과정을 한 번씩 진행합니다.
GitHub는 같은 isenswonju 계정으로 로그인해도 사용할 수 있습니다. 설치.bat이 각 PC의
Windows 사용자명을 변경 기록에 붙이므로 누가 만든 변경인지 구분할 수 있습니다.
다만 같은 요청을 동시에 수정하면 서로의 작업이 충돌할 수 있으므로, 한 사람이 작업을
끝낸 뒤 다른 사람이 시작하는 방식으로 운영합니다. Codex 계정은 각자 개인 계정을
사용해도 프로젝트 규칙과 자동 배포에는 영향이 없습니다.


2. 평소 유지보수
---------------

개발 명령을 외울 필요가 없습니다. 시작.bat을 열고 원하는 내용을 평문으로
말하면 됩니다. 프로젝트 규칙은 AGENTS.md에 들어 있어 개인 Codex 계정으로
로그인해도 같은 절차를 따릅니다.

변경이 완료되면 GitHub의 main 브랜치에 반영되고 다음 작업이 자동 실행됩니다.

- Python 회귀 테스트
- 오탐 감시
- 전체 정확도 검사
- 웹 테스트
- Hugging Face 검수 앱 배포와 실제 서비스 지문 확인
- Vercel 피드백·원본 보관함 백엔드 배포와 API 확인

검사가 실패하면 배포되지 않고 기존 서비스가 그대로 유지됩니다. 매일 새벽에
도는 별도 자동점검은 제거했습니다. 변경이 있을 때만 검사합니다.


3. 회사 소유 서비스
-------------------

GitHub 코드 저장소
  https://github.com/isenswonju/print-compare

검수 앱
  https://i-sens-print-compare.static.hf.space

피드백·원본 보관함
  https://print-compare-feedback.vercel.app
  Vercel 팀: i-sens

계정 정보는 같은 ZIP의 인수인계-계정.txt를 봅니다. 배포 토큰은 파일이 아니라
GitHub 저장소의 Actions Secrets(HF_TOKEN, VERCEL_TOKEN)에 등록되어 있습니다.


4. 꼭 지킬 것
-------------

- 실물 의료기기 라벨 이미지를 GitHub에 올리지 않습니다.
- 정확도 기준선(bench --accept)은 결과를 직접 확인하지 않고 승인하지 않습니다.
- 피드백을 처리하면 앱에서 확인 상태까지 바꿉니다.
- 보관함 목록을 비어 있는 값으로 덮어쓰지 않습니다.
- IndexedDB 버전을 올리지 않습니다.


5. 문제가 생겼을 때
-------------------

시작.bat을 열고 다음처럼 말하면 됩니다.

  지금 상태를 확인하고, 실패한 검사가 있으면 원인을 쉽게 설명해서 고쳐줘.

설치 결과에 [필요]가 있으면 적힌 안내대로 처리한 뒤 설치.bat을 다시 실행합니다.
설치 프로그램은 여러 번 실행해도 안전합니다.


6. 인수인계 완료 확인
--------------------

[ ] 설치.bat 결과가 모두 [완료]다
[ ] GitHub 저장소가 열린다
[ ] 시작.bat으로 Codex 대화창이 열린다
[ ] 검수 앱이 열린다
[ ] 원본 보관함의 기존 목록이 보인다
[ ] 피드백 페이지가 열린다


7. 2026-09-04 현재 상태
----------------------

정확도 기준선과 같은 macOS arm64 환경에서 자동 검증하도록 통일했습니다. 회귀 테스트,
오탐 감시, 전체 정확도 검사, 웹 테스트, Hugging Face 검수 앱 배포, Vercel 피드백·원본
보관함 배포와 API 확인까지 모두 자동 실행되며 최종 점검을 통과했습니다.
